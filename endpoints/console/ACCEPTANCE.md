## 验收流程

1. **代码审查**：检查代码规范、架构合规性
2. **单元测试**：运行 `cargo test` 确保所有测试通过
3. **集成测试**：使用 fake-client.mjs 进行端到端测试
4. **性能测试**：验证大量会话时的性能表现
5. **文档检查**：确认 README 和 API 文档完整性
