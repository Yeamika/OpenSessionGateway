# OpenSessionGateway

Workspace for the OpenSessionGateway project.

## Modules

- `sever/`: server-side contracts and implementation skeleton
- `client-library/`: reusable WS client library skeleton
- `client-template/`: blank client template for new integrations
- `client-opencode-plusxxx/`: OpenCode plugin implementation area
